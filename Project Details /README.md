# Machine Learning Based Atmospheric Data Analysis and Prediction

## 📌 Overview

This project analyzes atmospheric data using Python and
Machine Learning techniques. Historical atmospheric parameters
are analyzed to identify patterns and relationships, and
Machine Learning models are used to predict the temperature
for the next hour.

## 🎯 Objectives

- Analyze atmospheric conditions
- Perform data cleaning and preprocessing
- Identify atmospheric patterns
- Visualize atmospheric parameters
- Build Machine Learning models
- Predict next-hour temperature
- Compare model performance
- Visualize results using Power BI

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Power BI

## 📊 Dataset

The dataset is obtained from NASA POWER and contains
hourly atmospheric observations.

Main parameters include:

- Temperature
- Humidity
- Pressure
- Wind Speed
- Wind Direction
- Solar Radiation
- Cloud Amount
- Air Density
- Specific Humidity

## 🤖 Machine Learning Models

Two models were developed:

1. Linear Regression
2. Random Forest Regression

### Evaluation Metrics

- MAE
- RMSE
- R² Score

## 📈 Dashboard

The Power BI dashboard presents:

- Temperature trends
- Humidity analysis
- Atmospheric parameter relationships
- Actual vs predicted temperature
- Model performance
- Feature importance
